# Driver Alert (phone app)

Expo SDK 58 · React Native 0.88 · Android **development build** (not Expo Go).

```bash
npm ci
npm run android        # build + install the dev build on the USB-connected phone, start Metro
npm start              # Metro only, for an already-installed dev build
npm run adb:reverse    # phone localhost:8081/8000 → this laptop
npm run lint && npm run typecheck
```

- The workflow, toolchain and errors are in `../../.claude/skills/mobile-dev/SKILL.md`, and phone control (logs, screenshots, permissions) is in `../../.claude/skills/android-device/SKILL.md`.
- How alerts sound, flash and wake the phone: `../../.claude/knowledge/android-alerting.md`.
- `android/` is generated by `npm run prebuild` from `app.json` + `plugins/`. Don't edit it.
- Alert sounds in `assets/sounds/` come from `node ../../tools/gen-sounds.mjs`.
