# Dashboard dev workflow (`frontend/dashboard`)

Stack rules are in `frontend/dashboard/CLAUDE.md` (from the starter) and project rules in `.claude/rules/dashboard.md`. Run commands from `frontend/dashboard/`.

```bash
npm run dev                 # http://localhost:5173 ; /api (+ WebSocket) and /hubs proxied to VITE_API_URL (.env → http://localhost:8000)
npm run dev -- --host       # also reachable from other devices on the LAN (firewall: port 5173)
npm run build               # tsc -b && vite build: the verification step
npm run lint                # 1 expected warning (DataTable: react-hooks/incompatible-library)
npx shadcn@latest add dialog tabs tooltip   # new shadcn components → src/components/ui/
```

- The **showcase** at `http://localhost:5173/usage-examples` is the living documentation of every starter component. Update its page
  when you change a shared component.
- **Don't kill the user's running `npm run dev`.** Verify on another port: `npx vite --port 5179 --strictPort`.
- After moving or renaming files, the user's dev server must be restarted (Vite serves stale transforms).
- `.env` is gitignored. Copy it from `.env.example` on a fresh clone.

## Visual check without asking the user

```bash
npm run build && npx vite preview --port 4173 --strictPort     # run the preview in the background
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu \
  --user-data-dir=<scratchpad>/chrome --window-size=1400,900 --virtual-time-budget=6000 \
  --screenshot=<scratchpad>/dash.png http://localhost:4173/
```
Then Read the PNG. `--dump-dom` instead of `--screenshot` prints the rendered HTML. Animations: take two screenshots at different
`--virtual-time-budget` values to catch the pulse in both states.

## Sounds

`public/sounds/{chime,alarm_warning,alarm_critical}.wav` are generated by `node tools/gen-sounds.mjs` from the repo root. Browsers need one
user gesture before audio plays, so the UI needs an "Arm sound" interaction.
