# Dashboard rules (project-specific)

The stack rules (imports, Hugeicons, shadcn, one-component-per-folder, React Compiler lint rules, gotchas) are in
`frontend/dashboard/CLAUDE.md`, which carries over from the user's hackathon starter. This file adds what is specific to this project.
Workflow: skill `dashboard-dev`. Live data: skill `backend-local`.

- **Purpose:** a mock of the car's own screen, showing how the car reacts. That means the dashboard lamp (`response.dashboard_light`), the
  score gauge + level, behaviour icons lit from `active_behaviors` (driven by data, so unknown labels still render), a seat-vibration
  indicator (`vibrate_seat`), sounds (`sound` low/high, the `emergency` event), `response.message`, and a trip summary on `trip_ended`.
  It also shows a **QR code** of the WS address for the phone.
- **Contract = `docs/API.md`.** Copy its §4 types verbatim into `src/api/types.ts` (identical to mobile). Use only its routes and fields,
  never compute levels, and execute `response`. CORS is `*`, so REST can go direct or through the Vite proxy.
- **Sim panel (proposal, needs team OK):** behaviour toggles + a speed slider that `POST /telemetry` every second, standing in for the camera
  models in demos. Keep it behind a clearly labelled "Simulator" section. See `.claude/knowledge/contract-notes.md`.
- **Transport:** plain WebSocket (`/api/v1/ws`) via `src/hooks/useLive.ts` (never-give-up reconnect, the API.md §6 pattern). SignalR was removed
  on 2026-11-06. The car screen lives in `src/pages/CarScreen/`. Add `?sim` to the URL to open the simulator panel on load.
- **Sound:** browsers block audio until a user gesture, so put an "Arm sound" button / first-click unlock before the demo. The WAVs
  live in `public/sounds/`, generated by `node tools/gen-sounds.mjs`.
- **Flashing ≤ 3 Hz** (D14). Use theme tokens. Lamp colours (`#22C55E` / `#A3E635` / `#FACC15` / `#EF4444`, from API.md §7) go in CSS variables.
- In dev, `/api` (including the WebSocket) and `/hubs` proxy to `VITE_API_URL` (`.env` → `http://localhost:8000`).
- **Done means:** `npm run build` and `npm run lint` pass in `frontend/dashboard`, plus a headless-Chrome screenshot check for visual changes.
